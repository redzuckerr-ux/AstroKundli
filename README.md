# AstroKundli
Mobile-friendly static PWA prototype.

Includes broad sign-based readings for all 12 rashis; a preliminary Rashi compatibility overview; and Sade Sati/Dhaiya classification from the selected natal Moon sign and manually selected sidereal Saturn sign.

Limitations: this prototype does not calculate birth charts, planetary ephemerides, Saturn transit dates, or a verified 36-guna Ashtakoota score. The month selector changes the report label only; the broad horoscope themes are not recalculated for each month or based on planetary transits. Astrology is not scientifically established as a predictive method.

Deploy: upload index.html, manifest.webmanifest, sw.js and README.md to the root of a NEW GitHub repository. Enable GitHub Pages from main / root. Open the HTTPS site in Chrome and choose Install app / Add to Home screen.
